# StockManager

Aplicación Android de inventario offline para registrar entradas y salidas de mercancía en almacenes sin conexión a internet. Los movimientos se guardan en una base de datos local (Room / SQLite) y se envían al servidor central con el botón Sincronizar cuando el dispositivo tiene conexión.

Práctica AVS.03.02.01 Persistencia y acceso a datos — Desarrollo de aplicaciones móviles, UTEZ.

## Ejecución

1. Abrir la carpeta en Android Studio y esperar la sincronización de Gradle.
2. Ejecutar en un emulador o dispositivo con Android 8.0 (API 26) o superior.
